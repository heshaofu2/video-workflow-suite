## 职责与位置

负责理解目标、选择能力、安排顺序、衔接产物和汇总交付。先读取 [video-shared](../video-shared/SKILL.md)：公共规则由它维护，确定性操作统一由本地 `video-cli` 执行，领域 Skill 维护业务判断，本入口只做跨领域编排。

本地入口、共享层和领域能力完整存放在当前项目的 `.agents/skills/` 下，以相邻目录引用。ChatCut 继续使用官方配套 Skill。

## 选择能力

按本次目标只读取需要的 Skill，再读取它要求的参考资料。以下路径均相对于本入口目录：

| 用户目标 | 平级能力 | 主要交付 |
|---|---|---|
| 视频或音频转文字、补说话人标签 | [video-to-text](../video-to-text/SKILL.md) | 带时间戳的文字稿、JSON 和字幕 |
| 从已有文本梳理话题、观点、金句、争议和行动项 | [insight-extractor](../insight-extractor/SKILL.md) | 观点摘要与来源定位 |
| 从长视频按话题、说话人或时间范围切出短片 | [video-clipper](../video-clipper/SKILL.md) | 选段清单与粗剪片段 |
| 删除重录、重复讲述和未完成起句，保留完整表达 | [speech-video-dedup](../speech-video-dedup/SKILL.md) | 去重候选、核对预览、剪辑报告或清理后的完整视频 |
| 将已有字幕按语义重分为短句 | [subtitle-resegment](../subtitle-resegment/SKILL.md) | 新的短句 SRT |
| 评估开头吸引力、内容推进和互动诱因 | [clip-quality-monitor](../clip-quality-monitor/SKILL.md) | 有原文依据的文案诊断 |
| 明确使用 ChatCut 或继续其工程 | ChatCut 官方 `talking-head-guide` 及相应配套 Skill | 工程内剪辑、字幕或用户要求的包装 |

ChatCut 本机 Desktop 配套入口通常为 `~/.agents/skills/chatcut-talking-head-guide/SKILL.md`；优先使用当前会话已提供的官方版本。

## 明确任务范围

- 已有工具、工程、素材路径、选段或确认剪法时沿用。不要因为某个工具可用就改变用户选择。
- “只转写”“只评价”“找重复看看”分别只做相应工作，不扩展成完整成片。
- 只有“帮我剪一下”等目标不足的请求，先确认是保留完整讲述并清理，还是从长视频提炼短片。缺少素材时先查用户路径和项目上下文，再索取必要信息。
- 缺少某项本地能力时先在当前工作目录查找；不改用全局同名副本，不自动下载或重装。ChatCut 官方依赖则从其插件或 Desktop 配套来源查找。

## 编排组合任务

### 长视频切短片

按需要执行 `video-to-text` → `insight-extractor` → `video-clipper`。已有转写、摘要或明确时间范围时跳过已满足的环节。选段完整性检查与确认由 `video-clipper` 负责。

粗剪与去静音不能代表语义去重已经完成。用户要求“每条也剪干净”时再接续 `speech-video-dedup`；未要求时不追加精剪。

### 完整口播或课程去重

使用 `speech-video-dedup` 检查全片及剪口。需要转写时统一调用 `video-to-text`；复用和后端选择以共享转写契约为准，去重不再维护第二套识别流程。用户未要求时不把完整课程压缩成短视频。

### 字幕与质量诊断

需要字幕时，先确定最终剪辑，再取得对应成片时间线的 SRT 和必要词级时间，最后调用 `subtitle-resegment`。只有原片转写时，必须按实际剪辑映射转换或对成片重新转写，不能直接套用。

`clip-quality-monitor` 可在选段时辅助判断，也可在剪后做文案诊断；它只依据文字给建议，不代表实际播放、音画或平台效果已验证。

### 指定 ChatCut

用户选择 ChatCut 时用其官方流程完成目标，不先在外部剪完再擅自导入。需要文本分析时可使用平级的观点提炼或质量诊断能力。

明确指定 Desktop 或本地工程时使用 Desktop 工具，明确指定云端项目时使用相应连接。两者皆可用且工程归属不清时先查项目上下文，仍不确定再询问。先确定语音时间线，再制作用户要求的字幕、配乐和视觉包装。

## 产物衔接

- 为本次任务确定一个产物目录，各阶段沿用。目录规则和转写复用、时间基准统一引用共享层，不在每个阶段重建工作区。
- 跨阶段传递源文件身份、转写覆盖范围和实际剪辑映射，避免把一个阶段的时间戳误当成另一个阶段的时间戳。
- 沿用各能力的原片保护、确认和导出规则，保留本次已确认的选段与剪点。

## 交付

提供本次要求的可打开产物及路径，说明调用了哪些能力、处理了什么范围。选段完整性、接点与画面检查、技术检查和文案诊断分别按实际完成程度汇报；一项通过不代表其余已验证。
