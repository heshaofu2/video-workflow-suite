## 定位（先读这一段）

**输入是逐字稿，不是平台后台数据。** 3 秒完播率、整体完播率、互动率本质是平台实测指标，光凭逐字稿**测不出真实数值**。本模块做的是**基于文案本身的「预判 + 诊断」**：判断这条文案大概率能不能扛住前 3 秒、能不能被看到底、能不能勾起互动，并**定位问题原文 + 给改写建议**。

**因此：只给「评级 / 相对档位」，不编造百分比。** 说"3 秒完播偏弱"，不说"预测 3 秒完播率 41%"——后者是伪精确、是臆测。

## 输入

一条短视频的逐字稿，来源可以是：
- 用户直接粘贴的口播稿 / 逐字稿
- 某条切片对应的转写片段：通过 `transcript read` 按范围读取，不在本 Skill 另写 JSON 取段代码。

```bash
"$VIDEO_CLI" transcript read --input "$OUTDIR/transcript.json" \
  --start 0:16:20 --end 0:38:20
```

评审前先跟用户确认两件事（影响判据）：**目标平台**（抖音 / 视频号 / 小红书，节奏与互动习惯不同）、**目标人群**（决定钩子说给谁听）。用户没说就按通用短视频标准评，并在报告里注明。

## 三项指标的评判方法

### 指标 1：3 秒完播率 —— 看「开头钩子」

决定它的**只有前 3 秒**（口播约前 15–25 字、1–2 句话）。评判这段话：

- **有没有立刻给理由留下来**：利益点 / 悬念 / 冲突 / 反常识结论 / 戳中的痛点，四选一即可
- **有没有制造信息缺口**：抛一个让人想知道答案的问题或反常识判断，勾好奇心
- **有没有人群锚定**：让目标人群一秒认出"这是说给我听的"
- **前 3 秒有没有废话**：自我介绍、寒暄、"大家好今天来聊一聊"、"在开始之前"、"呃那个"——这些是 3 秒完播的头号杀手

**拉分红线**（命中任一即判「弱」）：开头是自我介绍 / 背景铺垫 / 平淡陈述 / 术语堆砌且无钩子。

**产出**：评级 + 摘出前 3 秒原文 + 诊断 + **给 1–2 个替代开头改写**。

### 指标 2：整体完播率 —— 看「节奏 × 信息增量」

决定它的是**全程有没有持续给「继续看下去的理由」**。逐段扫描逐字稿：

- **信息密度**：是否持续有信息增量？有没有大段冗余、重复、绕圈、口水话、无效铺垫
- **钩子链 / 推进结构**：有没有"接下来 / 更关键的是 / 第三点 / 但是"这类把注意力往后拉的结构；观点是否层层递进（问题→解法、总→分、逐层加码）
- **时长匹配**：内容量能不能撑起这个时长；一个单薄观点拖太长必掉完播
- **结尾回报**：结尾有没有收束 / 升华 / 反转，给"看到最后"一个回报；还是戛然而止、虎头蛇尾
- **流失点定位**：找出逐字稿里**最可能让人划走的那一段**（从哪句开始拖、开始散）

**拉分红线**：开头即冗长铺垫；中段大段重复/绕圈；只有一个观点却硬撑长时长；无结尾。

**产出**：评级 + **标出「从这里开始容易流失」的原文位置** + 精简/提速建议（砍哪段、哪里加钩子）。

### 指标 3：互动倾向 —— 看「评论 / 点赞 / 转发 / 收藏的诱因」

决定它的是**内容有没有给用户「想说点什么 / 想转发 / 想收藏」的理由**。温吞、四平八稳的内容没人互动。检查：

- **观点是否鲜明可站队**：有没有能让人"我同意 / 我反对"的鲜明主张、轻度争议？（最强的评论驱动力）
- **有没有提问 / 号召**：有没有直接向观众抛问题、征集看法、引导去评论区
- **情绪触发**：共鸣（说出心里话）/ 意外（反常识）/ 认同 / 轻度冒犯，命中几个
- **收藏价值**：有没有可保存复用的干货（清单、方法、判断标准）驱动收藏转发
- **身份表达**：内容能不能让人转发以表达身份立场（"这说的就是我 / 我早就这么觉得"）
- **评论区诱饵**：有没有开放性留白、待补充点，勾人来补一句

**拉分红线**：全程平铺客观陈述、无观点无情绪；没有任何提问或号召；纯"我讲你听"、不留讨论空间。

**产出**：评级 + 现有互动诱因盘点 + **具体加法**（补一个争议钩子 / 结尾提问 / 征集话术）。

## 评审流程

1. **确认上下文**：目标平台、目标人群（缺则按通用标准并注明）。
2. **通读逐字稿**：切出前 3 秒那句、标注话题推进结构、找情绪/观点高低点。
3. **逐项判**：按上面三套判据打评级，每条结论**必须引用逐字稿原文**作依据，不空评。
4. **出报告**：按下方模板，最后收敛成「最该改的 3 件事」。

## 评审原则

1. **只判文案能决定的部分**：画面、封面、BGM、账号权重不在逐字稿里，不评（用户另外问再说）。
2. **每条结论都要有原文依据**：引用逐字稿具体句子，不给"感觉不错"式空评。
3. **不编数值**：给档位不给假百分比（见「定位」）。
4. **改写要能直接用**：建议给成可直接念的话术，不给"建议增强开头吸引力"这种正确的废话。
5. **粗剪 ≠ 成品短视频**：若输入是长切片粗剪（几十分钟、开头是自我介绍），如实说明它是素材而非成片，评的是"若照此发布"的表现。
